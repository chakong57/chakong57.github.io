此设置页受管理员密码保护。
方式一（Fine-grained）：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → ① Repository access 勾选博客仓库；② Contents 权限选 Read and write。
方式二（Classic，简单直接）：打开 https://github.com/settings/tokens → Generate new token (classic) → 仓库公开勾选 public_repo、仓库私有勾选 repo → 生成后复制粘贴到上方。
Token 只保存在「当前浏览器」中，游客看不到也用不了；请勿泄露，泄露等于交出仓库写权限。
